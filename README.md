Playlist Maker

Приложение для поиска и составления музыкальных плейлистов на базе API iTunes. Есть функция проигрывания фрагмента трека, просмотра информации об альбоме, добавления трека в избранные.
Используемый стек: Kotlin, MVVM, Coroutines, Koin, Room, Fragment, Jetpack Navigation, Retrofit
